# AI Usage Declaration

Artificial intelligence tools, primarily ChatGPT, were used as a development aid during the creation of SubTrack.

AI assistance was mainly used during the initial setup and planning of the project. This included helping establish the base SwiftUI/MVVM project structure, organising the Domain, Data, Presentation and Support layers, suggesting appropriate file and type names, and helping structure the Use Case and repository pattern required by the assessment. AI was also used occasionally for code examples, debugging guidance and suggestions while implementing and testing the application.

I was responsible for integrating the project in Xcode, completing and modifying the implementation, adding and refining application functionality, reviewing the generated or suggested code, resolving issues, running the application, testing its behaviour and confirming that the final system met the assessment requirements.

All submitted code was reviewed and tested by me before submission. AI was used as a development support tool rather than as a substitute for understanding or verifying the final implementation.
